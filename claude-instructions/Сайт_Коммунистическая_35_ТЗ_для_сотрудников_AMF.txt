ТЗ для сотрудников AMF: сайт аренды офисов по референсу (okt42.center)
1) Цель
Сделать сайт бизнес-центра по логике и структуре референса (по вашим скринам) с:
публичной частью (страницы + каталог помещений)
админкой для управления контентом
заявками из форм
базовым SEO (ЧПУ, мета, sitemap/robots)
Ключевой сценарий: Главная → Актуальные предложения/каталог → карточка помещения → заявка.
2) Страницы и блоки
2.1 Общие элементы (на всех страницах)
TopBar: телефоны, email, адрес, иконки соцсетей
Header: логотип + меню Пункты: Аренда офисов / Доп. услуги (dropdown) / Фотогалерея / Расположение / О нас / Контакты
Fixed-кнопка “Напишите нам” (справа, плавающая) → открывает модальную форму
Footer: дубли контактов + копирайт
2.2 Главная
Блоки в порядке:
Hero-слайдер (заголовок/подзаголовок/кнопка/картинка, точки/стрелки)
Актуальные предложения (карточки помещений с ценой/площадью/этажом и CTA)
Почему арендаторы выбирают нас? (8 преимуществ с иконками)
Наши арендаторы (логотипы)
Большая форма (имя/телефон/email/сообщение + согласие ПДн)
Карта
Footer
2.3 Аренда офисов (листинг) /offices
Сетка карточек помещений
Фильтры:
статус: все / свободно / бронь / сдано
площадь от/до
этаж
цена от/до
Сортировка: цена / площадь / этаж
Пагинация
Логика CTA на карточке:
free → “Оставить заявку”
reserved → “Раннее бронирование”
rented → “Уточнить наличие”
2.4 Карточка помещения /offices/:slug
Галерея (слайдер + миниатюры)
Таблица характеристик (показывать только заполненные поля)
Цена/мес + CTA “Оставить заявку”
Описание
“Подходит для” (список)
2.5 Доп. услуги /services и /services/:slug
Страница списка услуг
Детальная услуги: описание + фото/иконка + цены/таблица + CTA “Оставить заявку”
Для “Реклама” — поддержка нескольких блоков/опций (как на скринах: LED экран, лайтбоксы, лифты и т.д.)
2.6 Фотогалерея /gallery
Сетка фото 3–4 в ряд (адаптив)
Лайтбокс просмотр
2.7 Контакты /contacts
Контактные данные (адрес, телефоны, email, график)
Соцсети
Реквизиты (текстовый блок)
Форма
Карта
3) Данные и сущности (что хранить и чем управлять из админки)
3.1 Помещение (Room)
Поля:
title, slug
roomNumber, type
area, floor
layoutType
water (bool), wc (bool), windows (bool)
entrance (text)
rentType, internet
minRentTerm
priceMonth, priceM2 (опционально)
description (richtext)
suitableFor (список)
status: free/reserved/rented
showOnHome (bool)
photos[] (сортировка)
3.2 Главная (контент)
heroSlides[] (сортировка, активность)
advantages[] (8 шт, иконка+текст)
tenants[] (логотипы, сортировка)
3.3 Услуги (Service)
title, slug
content (richtext)
image
priceText (опц.)
options[] (для услуги “Реклама” и подобных)
SEO поля
3.4 Галерея
images[] (сортировка, подпись опц.)
3.5 Контакты (настройки)
phones[], email, address, workHours
socials (vk/wa/tg/avito…)
requisites (текст)
карта: провайдер + координаты
3.6 Заявки (Lead)
name, phone, email?, message?
roomId? (если заявка из карточки помещения)
pageUrl/utm? (опционально)
status new/processed
createdAt
4) Админка (MVP)
Должно быть:
Авторизация admin
CRUD: помещения + фото (загрузка + сортировка drag&drop)
CRUD: heroSlides
CRUD: advantages
CRUD: tenants
CRUD: services + options
CRUD: gallery
Просмотр заявок + смена статуса processed
Настройки контактов (1 страница)
5) SEO и техтребования
ЧПУ роуты (см. выше)
Meta title/description (хотя бы на Rooms/Services/Pages)
sitemap.xml
robots.txt
404 page
Оптимизация изображений + lazyload
Формы: серверная валидация + антиспам (honeypot + rate limit)
